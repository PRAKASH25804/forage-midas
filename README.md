# Midas – JPMorgan Chase & Co Advanced Software Engineering Program

This repository contains my completed work for the **JPMorgan Chase & Co Advanced Software Engineering Virtual Experience Program (Forage)**.

## 🚀 Project Overview
The Midas project simulates a real-world financial microservice that:
- Processes Kafka events
- Maintains account balances
- Exposes REST APIs using Spring Boot
- Uses JPA with an in-memory H2 database

## 🧠 Key Concepts & Skills
- Java 17
- Spring Boot
- Apache Kafka (Producer & Consumer)
- REST APIs
- Maven
- JPA / Hibernate
- Embedded Tomcat
- Automated Testing (JUnit)
